# Household supplies — система контроля домашних запасов

## Назначение

Проект предназначен для учёта продуктов, бытовой химии и других товаров,
хранящихся дома. Система помогает пользователю отслеживать остатки,
вовремя пополнять запасы и контролировать сроки годности.
Приложение позволяет:

* просматривать запасы;
* находить запасы по названию;
* фильтровать запасы по категории;
* сортировать запасы по названию и количеству;
* добавлять новые запасы;
* удалять запасы вместе со связанными операциями;
* списывать и пополнять запасы;
* отменять операции с восстановлением остатка;
* просматривать журнал операций;
* получать статистику по категориям и операциям;
* хранить данные между запусками приложения.

## Целевая аудитория

- Владельцы квартир и домов, желающие навести порядок в кладовой;
- Семьи, ведущие совместное хозяйство;
- Люди, склонные к планированию закупок и экономии бюджета.

## Предметная область

Основными объектами предметной области являются:

* категория;
* запас;
* операция;
* пользователь.

Пользователь создаёт запасы и фиксирует их приход или расход.
Каждый запас относится к категории и имеет текущее количество с
единицей измерения. Каждая операция связана с конкретным запасом
и имеет тип (`consume` — расход, `restock` — приход) и дату.
Отменённая операция возвращает запас в прежнее состояние.

## Основные сущности

### Category — категория

Объект `Category` представляет группу запасов (продукты, химия,
гигиена и т.п.).
Основные атрибуты:
* `id` — уникальный идентификатор категории;
* `name` — название категории;
* `description` — описание.
Основные методы:
* `__str__()` — строковое представление категории;
* `from_data()` — создание объекта `Category` из набора данных;
* `is_system()` — проверка, относится ли название к системным.

### User — пользователь

Объект `User` представляет пользователя системы.
Основные атрибуты:
* `id` — уникальный идентификатор пользователя;
* `name` — имя пользователя;
* `email` — адрес электронной почты.
Основные методы:
* `__str__()` — строковое представление пользователя;
* `from_data()` — создание объекта `User` из набора данных.

### Stock — запас

Объект `Stock` представляет конкретный запас (товар).
Основные атрибуты:
* `id` — уникальный идентификатор запаса;
* `name` — название запаса;
* `category` — объект `Category`;
* `quantity` — текущее количество;
* `unit` — единица измерения (кг/шт/л);
* `expiry_date` — срок годности или `None`.
Основные методы:
* `change_quantity()` — изменение количества на заданную величину;
* `__str__()` — строковое представление запаса;
* `from_data()` — создание объекта `Stock` из набора данных;
* `to_data()` — преобразование объекта `Stock` в данные JSON.

### Operation — операция

Объект `Operation` представляет операцию прихода или расхода запаса.
Основные атрибуты:
* `id` — уникальный идентификатор операции;
* `stock` — объект `Stock`;
* `type` — тип операции (`consume` / `restock`);
* `amount` — количество;
* `date` — дата операции.
Основные методы:
* `apply()` — применить операцию к связанному запасу;
* `rollback()` — откатить операцию;
* `__str__()` — строковое представление операции;
* `from_data()` — создание объекта `Operation` из набора данных.

## Основные операции

### Работа с категориями

* добавление категории;
* поиск категории по названию;
* просмотр списка категорий.

### Работа с пользователями

* создание пользователя;
* поиск пользователя;
* просмотр информации о пользователях.

### Работа с запасами

* добавление запаса;
* поиск запаса по названию;
* фильтрация запасов по категории;
* сортировка запасов по названию и количеству;
* удаление запаса вместе со связанными операциями;
* просмотр списка запасов.

### Работа с операциями

* создание операции расхода;
* создание операции прихода;
* отмена операции;
* просмотр списка операций;
* просмотр статистики по операциям.

При списании проверяется, что количество не превышает текущий
остаток. При отмене операции состояние связанного запаса
восстанавливается.

## Хранение данных

Данные приложения хранятся в JSON-файлах:
* `data/categories.json`;
* `data/users.json`;
* `data/stocks.json`;
* `data/operations.json`.

При загрузке данные из JSON преобразуются в объекты `Category`,
`User`, `Stock` и `Operation`.

При сохранении объекты преобразуются в данные JSON.

Для связи запаса с категорией в `stocks.json` используется её
идентификатор `category_id`. Для связи операции с запасом в
`operations.json` используется `stock_id`.

## Назначение модулей
### main.py
Точка входа в приложение.
Отвечает за:
* запуск приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### models/categories.py
Содержит класс Category и функции работы с категориями.

### models/users.py
Содержит класс User и функции работы с пользователями.

### models/stocks.py
Содержит класс Stock и функции работы с запасами.

### models/operations.py
Содержит класс Operation и функции работы с операциями.

### storage.py
Отвечает за загрузку и сохранение данных.
Выполняет преобразование:
* JSON → объекты Python;
* объекты Python → JSON.

### utils.py
Содержит вспомогательные функции:
* input_int() — безопасный ввод целого числа;
* input_float() — безопасный ввод вещественного числа;
* input_date() — безопасный ввод даты;
* input_nonempty() — безопасный ввод непустой строки.

### tests/
Содержит автоматизированные тесты проекта.
