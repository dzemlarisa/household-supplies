# Household supplies — система контроля домашних запасов

## Назначение

Проект предназначен для учёта продуктов, бытовой химии и других товаров,
хранящихся дома. Система помогает пользователю отслеживать остатки,
вовремя пополнять запасы и контролировать сроки годности.
Приложение позволяет:

* просматривать запасы;
* находить запасы по названию;
* фильтровать запасы по категории;
* сортировать запасы по названию и количеству;
* добавлять новые запасы;
* удалять запасы;
* списывать и пополнять запасы;
* получать статистику по категориям;
* хранить данные между запусками приложения.


Приложение доступно в двух вариантах:

* консольная версия — `python main.py`;
* веб-версия на Django — `python manage.py runserver`.

## Используемые технологии

## Целевая аудитория

- Владельцы квартир и домов, желающие навести порядок в кладовой;
- Семьи, ведущие совместное хозяйство;
- Люди, склонные к планированию закупок и экономии бюджета.

## Предметная область

Основными объектами предметной области являются:

* категория;
* запас;
* пользователь.

Пользователь создаёт запасы и фиксирует их приход или расход.
Каждый запас относится к категории и имеет текущее количество с
единицей измерения. Каждая операция связана с конкретным запасом
и имеет тип (`consume` — расход, `restock` — приход) и дату.
Отменённая операция возвращает запас в прежнее состояние.

## Основные сущности

### Category — категория

Объект `Category` представляет группу запасов (продукты, химия,
гигиена и т.п.).
Основные атрибуты:
* `id` — уникальный идентификатор категории;
* `name` — название категории;
* `description` — описание.
Основные методы:
* `__str__()` — строковое представление категории;
* `from_data()` — создание объекта `Category` из набора данных;
* `is_system()` — проверка, относится ли название к системным.

### User — пользователь

Объект `User` представляет пользователя системы.
Основные атрибуты:
* `id` — уникальный идентификатор пользователя;
* `name` — имя пользователя;
* `email` — адрес электронной почты.
Основные методы:
* `__str__()` — строковое представление пользователя;
* `from_data()` — создание объекта `User` из набора данных.

### Stock — запас

Объект `Stock` представляет конкретный запас (товар).
Основные атрибуты:
* `id` — уникальный идентификатор запаса;
* `name` — название запаса;
* `category` — объект `Category`;
* `quantity` — текущее количество;
* `unit` — единица измерения (кг/шт/л);
* `expiry_date` — срок годности или `None`.
Основные методы:
* `change_quantity()` — изменение количества на заданную величину;
* `__str__()` — строковое представление запаса;
* `from_data()` — создание объекта `Stock` из набора данных;
* `to_data()` — преобразование объекта `Stock` в данные JSON.

## Структура базы данных
В базе данных `data/homestock.sqlite` спроектированы три таблицы:

| Таблица | Поле | Тип данных | Описание |
| :--- | :--- | :--- | :--- |
| **categories** | `id` | INTEGER | Уникальный идентификатор категории |
| | `name` | TEXT | Название категории (например, "продукты") |
| | `description` | TEXT | Описание категории |
| **users** | `id` | INTEGER | Уникальный идентификатор пользователя |
| | `name` | TEXT | Имя владельца запасов |
| | `email` | TEXT | Электронная почта |
| **stocks** | `id` | INTEGER | Уникальный идентификатор запаса |
| | `category_id` | INTEGER | Ссылка на категорию |
| | `user_id` | INTEGER | Ссылка на владельца |
| | `name` | TEXT | Название запаса (например, "Рис") |
| | `quantity` | REAL | Текущее количество |
| | `unit` | TEXT | Единица измерения (кг, шт, л) |
| | `expiry_date` | TEXT | Срок годности (в формате YYYY-MM-DD) |

## Первичные и внешние ключи
- В каждой таблице поле `id` является **первичным ключом** (`PRIMARY KEY`), который однозначно идентифицирует запись.
- В таблице `stocks` определены **внешние ключи** (`FOREIGN KEY`):
  - `category_id` ссылается на `categories.id` — каждый запас относится к конкретной категории;
  - `user_id` ссылается на `users.id` — каждый запас принадлежит конкретному пользователю (владельцу).
- При подключении к базе данных из Python выполняется команда `PRAGMA foreign_keys = ON;` для обеспечения целостности связей.

## Перечень SQL-запросов (`sql/queries.sql`)
В файле собраны SQL-запросы, реализующие функциональность проекта:
1.  **Выборка списков (SELECT):** получение списка всех запасов и пользователей.
2.  **Фильтрация (WHERE):** поиск запасов определенной категории или с количеством больше заданного.
3.  **Соединение таблиц (JOIN):** вывод запасов вместе с названиями их категорий и именами владельцев.
4.  **Агрегатные функции:** подсчет общего количества запасов (`COUNT`) и суммарного объема (`SUM`).
5.  **Группировка (GROUP BY):** подсчет количества запасов в каждой категории.
6.  **Фильтрация групп (HAVING):** поиск категорий, в которых хранится более одного вида запасов.

## Получение данных из SQLite в Django-представлениях
Представления (`views.py`) приложений `stocks` и `users` напрямую обращаются к базе данных с помощью стандартной библиотеки `sqlite3`. 
Для удобной работы в шаблонах используется настройка `conn.row_factory = sqlite3.Row`, которая позволяет обращаться к полям результата SQL-запроса по их именам (например, `{{ stock.name }}` или `{{ stock.category_name }}`), а не по индексам. Все значения, получаемые от пользователя, передаются в SQL-запросы через параметры `?` для защиты от SQL-инъекций.

## Страницы, отображающие данные из базы
Следующие страницы сайта получают данные напрямую из SQLite:
- `/stocks/` — список всех запасов с указанием категории;
- `/stocks/<id>/` — карточка конкретного запаса с ФИО владельца;
- `/users/` — список всех владельцев запасов;
- `/users/<id>/` — профиль владельца и список его запасов;
- `/users/statistics/` — страница со статистикой (количество запасов по категориям).
