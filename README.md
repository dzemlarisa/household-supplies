# Household supplies — система контроля домашних запасов

## Назначение

Проект предназначен для учёта продуктов, бытовой химии и других товаров,
хранящихся дома. Система помогает пользователю отслеживать остатки,
вовремя пополнять запасы и контролировать сроки годности.

## Целевая аудитория

- Владельцы квартир и домов, желающие навести порядок в кладовой;
- Семьи, ведущие совместное хозяйство;
- Люди, склонные к планированию закупок и экономии бюджета.

## Предметная область

Домашние запасы — это совокупность товаров, которые хранятся в доме
и периодически расходуются (крупы, консервы, бытовая химия, средства
гигиены и т.п.). Каждый запас относится к определённой категории,
имеет единицу измерения и текущее количество. При снижении количества
ниже заданного минимума пользователь получает уведомление о
необходимости пополнения.

## Основные сущности

- Пользователь
- Категория  
- Запас
- Количество

## Основные функции

- Регистрация и вход пользователя;
- Добавление, редактирование и удаление запасов;
- Управление категориями;
- Изменение количества (приход/расход);
- Просмотр списка запасов с фильтрацией по категории;
- Поиск запаса по названию.

## План развития проекта

**ПР1:** Консольный сценарий добавления запаса с проверкой ввода и определением статуса остатка.

**На следующих этапах планируется:** 
- Добавление структур данных (списки, словари) и классов `User`, `Category`, `Stock`.
- Сохранение данных в файл (JSON), загрузка при запуске.
- Добавление модуля отчётов и уведомлений о низком остатке.
- Графический интерфейс (Tkinter) или веб-версия (Flask).
